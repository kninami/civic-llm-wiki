# API (Application Programming Interface)

프로그램끼리 데이터를 주고받는 공식 창구. 서비스 제공자가 "이 주소로 이렇게 물어보면 이런 형식으로 답해주겠다"고 미리 약속해 열어둔 것.

**활동가에게 왜 중요한가**
- [[웹-스크래핑]]의 정식 대안. **깨지지 않고, 약관 문제가 없고, 응답 형식이 일정함**
- 자동화 도구를 만들 때 가장 먼저 확인할 것 — "공식 API가 있나?"
- 공공데이터는 생각보다 API가 많이 열려 있음. 예: 행정안전부 도로명주소 안내시스템(`business.juso.go.kr`)의 주소검색 API는 무료이며 응답에 우편번호가 포함됨

**스크래핑과 비교**

| | API | [[웹-스크래핑]] |
|---|---|---|
| 안정성 | 규격이 바뀌면 보통 사전 공지 | 예고 없이 깨짐 |
| 약관 | 허용된 사용 | 제한되는 경우가 많음 |
| 준비 | 승인키 발급 필요할 수 있음 | 바로 시작 가능 |
| 응답 | 정해진 형식(JSON 등) | HTML 전체에서 찾아내야 함 |

**주의**
- **무엇을 보내는지 확인할 것** — API 호출에도 데이터가 외부로 나감. 개인정보가 섞이면 [[guardrails]] G3-⑥("외부 API와 연계될 경우 전송되는 데이터의 범위 확인")에 해당
- **승인키는 코드에 그대로 적지 말 것** — 위키나 저장소에 올리면 그대로 노출됨
- 호출 횟수 제한이 있는 경우가 많음
