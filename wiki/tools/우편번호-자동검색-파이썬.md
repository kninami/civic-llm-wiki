# 파이썬 — 주소록 파일에 우편번호 채우기

> 엑셀/CSV 주소록을 올려두고 요청하면 우편번호 열을 붙여서 돌려줌.
> [[우편번호-자동검색]]의 파이썬 판. 스프레드시트를 열지 않고 파일 단위로 한 번에 처리.

**스크립트** — `우편번호채우기.py` (이 파일과 같은 폴더)

## 개요

- **[[우편번호-자동검색]]과 다른 점** — Apps Script 판은 시트를 열고 수식을 채워야 함. 이쪽은 **파일을 주고 요청하면 끝**
- 활동가가 코드를 볼 일이 없음. 엑셀 파일만 있으면 됨
- 수백~수천 건을 한 번에 처리하고, 끝나면 **성공/못찾음/실패 건수를 보고**함
- **AI를 쓰지 않음** (→ [[guardrails]] G6-③)
- 다만 주소가 외부(네이버)로 전송됨 → 「주의사항」

> [확인 필요] 실제 단체에서 쓴 이력 없음. 이 위키에서 만든 시범 도구

## 알아야 할 개념

- [[웹-스크래핑]] — 이 도구의 방식이자 최대 약점
- [[API]] — 스크래핑의 정식 대안

## 작동 방식

1. 엑셀/CSV를 읽고 **주소 열을 자동으로 찾음** (열 이름에 "주소"가 있거나, 값이 주소처럼 생긴 열)
2. 주소마다 네이버에 검색 요청 (1.5초 간격)
3. 결과 화면에서 우편번호를 꺼냄. **같은 주소는 한 번만 조회**하고 재사용
4. **원본은 그대로 두고** `<원본이름>_우편번호.xlsx`를 새로 만듦
5. 성공/못찾음/조회실패 건수를 화면에 보고

**사람이 개입하는 지점** — 끝나고 사람이 대조. 스크립트가 마지막 줄에 "최소 10건은 손으로 대조하세요"를 항상 출력함

## 사용법

**LLM에게 맡기는 경우 (권장)**

1. 주소록 파일을 이 저장소 아무 곳에나 둔다
2. 이렇게 요청한다 — *"주소록.xlsx에 우편번호 채워줘"*
3. 결과 파일과 함께 성공/실패 건수를 받는다
4. **최소 10건을 원본과 대조한다**

**직접 실행하는 경우**

```bash
pip install openpyxl        # 처음 한 번만

python3 우편번호채우기.py 주소록.xlsx              # 전체
python3 우편번호채우기.py 주소록.xlsx --개수 10     # 앞 10건만 (검증용)
python3 우편번호채우기.py 주소록.xlsx --열 "집주소"  # 주소 열 직접 지정
```

- `--개수`로 먼저 10건을 돌려 맞는지 보고 전체를 실행하는 것을 권함
- 검증 결과는 `_우편번호_샘플.xlsx`로 따로 저장되어 전체 결과를 덮어쓰지 않음
- **원본 파일은 절대 수정하지 않음**

**결과 표시**

| 값 | 뜻 | 할 일 |
|---|---|---|
| `03745` | 정상 | 표본 대조 |
| `#못찾음` | 네이버에 우편번호가 안 뜨는 주소 (오래된 지번주소·신축·오타) | 주소를 확인하거나 손으로 채움 |
| `#조회실패` | 네트워크 오류 또는 네이버 차단 | 잠시 뒤 다시 실행 |
| (빈칸) | 주소 열이 비어 있던 행 | — |

**막히는 곳**

| 증상 | 원인 |
|---|---|
| `No module named 'openpyxl'` | `pip install openpyxl` 안 함 |
| `주소 열을 찾지 못했습니다` | `--열 "열이름"`으로 직접 지정 |
| 전부 `#조회실패` | 네이버 차단. `--간격`을 3 이상으로 올리고 나눠서 실행 |
| 전부 `#못찾음` | 네이버가 화면 구조를 바꿈. 스크립트의 `PATTERNS`를 다시 찾아야 함 |

**옮겨 심기 전에** — 행정안전부 도로명주소 API(`business.juso.go.kr`)가 우편번호를 무료로 제공함. 승인키 발급이 필요한 대신 **깨지지 않고 약관 문제도 없음**

## 주의사항

AI를 쓰지 않아 대부분 해당 없음. 해당하는 4개만.

| ID | 위험 | 완화 | 남은 위험 |
|---|---|---|---|
| **P1** 책임성 | 파일을 통째로 넘기므로 **한 번에 수백 건이 검증 없이 처리됨.** 틀린 우편번호로 우편물이 반송되면 책임은 단체에 | `--개수 10` 검증 모드 / 원본 미수정 / 끝날 때마다 대조 경고 출력 | 경고를 읽고도 대조하지 않으면 막을 방법이 없음 |
| **P4·G3** 개인정보 | **회원 주소 전체가 검색어로 네이버에 전송됨.** Apps Script 판보다 한 번에 나가는 양이 훨씬 많음. 네이버는 검색 질의를 로그로 남김 | 주소만 전송 (이름·연락처는 보내지 않음) / 중복 주소는 한 번만 조회 | 주소 전송 자체는 남음. **피해자 쉼터·활동가 자택처럼 주소만으로 민감한 항목은 파일에서 빼고 돌릴 것** |
| **G1** 정확성 | 네이버 화면이 바뀌면 결과가 틀어짐 | 빈칸 대신 `#못찾음`·`#조회실패`로 **실패를 눈에 보이게** 함 / 건수 보고 | `#못찾음`이 "주소가 이상함"인지 "도구가 깨짐"인지는 구분되지 않음. 갑자기 전부 `#못찾음`이면 후자 |
| **G4** 약관 | 네이버 검색 결과 자동 수집. 이용약관상 제한 소지. **대량 처리라 Apps Script 판보다 부담이 큼** | 요청 간격 1.5초 / 중복 제거 | 약관 위반 소지는 남음. 공식 API로 바꾸면 사라지는 항목 |

해당 없음 — **P2**(단순 반복이라 훈련 가치 없음) · **P3**(사람을 분류하지 않음) · **P5·G5**(AI 생성물 아님) · **P6·G6**(생성형 AI 미사용) · **G2**(생성 결과물 없음)

## 사례

### [2026-09-02] 제작 및 실측

- [[우편번호-자동검색]](Apps Script)을 파일 단위 처리로 옮긴 것
- **네이버 응답을 직접 확인함** — 우편번호가 서버 HTML에 그대로 들어 있어 브라우저 없이 추출 가능
- **오탐을 발견하고 고침** — `우편번호` 근처의 5자리 숫자를 느슨하게 찾으면, 블로그 본문의 *"(우편번호 12345)"* 같은 예시 문구를 집어옴. 존재하지 않는 주소에 `12345`가 나옴
  - → `우편번호</span>03745` / `우편번호 · 03745 · 복사` 두 가지 **구조를 그대로 요구**하는 방식으로 바꿔 해결
- **403 차단을 만나고 고침** — `User-Agent`만으로는 네이버가 막음. `Accept` 헤더가 있어야 통과
- 6행짜리 시험 주소록으로 끝까지 실행 — 성공 4 / 못찾음 1(오탐 테스트 주소, 의도된 결과) / 빈칸 1
- 확인한 것 — 원본 미수정 · 중복 주소 캐시 · CSV 입력 · 열 자동탐지 · 없는 파일/열 오류 메시지
- **확인 안 된 것** — 수백 건 규모에서 네이버가 차단하는 시점. 대량 실행 경험이 없음
