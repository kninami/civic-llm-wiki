# Google Sheets — 주소를 이용한 우편번호 검색 자동화 도구

> A열에 주소를 넣으면 B열에 우편번호가 채워짐. 네이버 검색 결과를 긁어오는 방식.
> 파일을 통째로 처리하려면 → [[우편번호-자동검색-파이썬]]

## 개요

- **해결하려는 문제** — 주소는 있는데 우편번호가 비어 있는 주소록. 소식지·감사장·총회 안내문 발송 전에 채워야 함
- **이전 방식** — 우체국 사이트에 주소를 하나씩 붙여넣고 우편번호를 복사. 수백 건이면 몇 시간
- **바뀐 것** — B열에 수식 한 번 채우면 전체가 한꺼번에 처리됨
- **AI를 쓰지 않음** — 생성형 AI 없이 되는 일 (→ [[guardrails]] G6-③). 이 위키가 권하는 방향의 자동화
- 다만 주소가 외부(네이버)로 전송됨. AI를 안 쓴다고 위험이 없는 것은 아님 → 「주의사항」

> [확인 필요] 만든 단체, 실제 처리 건수, 사용 기간 미확인

## 알아야 할 개념

- [[웹-스크래핑]] — 웹페이지에서 필요한 부분만 뽑아내는 것. 이 도구의 방식이자 최대 약점
- [[API]] — 스크래핑의 정식 대안. 공식으로 열어둔 데이터 창구

## 작동 방식

1. B열 수식이 A열 주소를 읽음
2. 네이버에 그 주소를 검색
3. 돌아온 화면에서 우편번호가 있는 위치의 값을 꺼냄
4. 셀에 표시

**사람이 개입하는 지점 — 없음.** 수식이 자동으로 돌고 결과가 바로 셀에 들어감

## 코드

```javascript
function getPostCode(address) {
  var searchUrl = "https://search.naver.com/search.naver?query=";
  var html = UrlFetchApp.fetch(searchUrl + address).getContentText();

  var $ = Cheerio.load(html);
  var postcode = $('#loc-main-section-root > section > div > div.uOjIX > div.hSQoe > div > span:nth-child(1)').text().substring(4,9);

  return postcode;
}
```

## 사용법

1. 스프레드시트 > 확장 프로그램 > **Apps Script**
2. **Cheerio 라이브러리 추가** (라이브러리 > ID 입력)  : 1ReeQ6WO8kKNxoaA_O0XEQ589cIrRvEBA9qcWpNqdOP17i47u6N9M5Xh0
3. 위 코드를 붙여넣고 저장
4. 시트 B2에 `=getPostCode(A2)` 입력 후 아래로 채우기
5. **처음 10건은 손으로 대조.** 맞으면 나머지 진행
6. 다 채워지면 B열 전체를 **값으로 붙여넣기**(Ctrl+Shift+V). 수식을 남겨두면 시트를 열 때마다 네이버에 요청이 다시 나감

**막히는 곳**

| 증상                       | 원인                                    |
| ------------------------ | ------------------------------------- |
| `Cheerio is not defined` | 2번을 빠뜨림                               |
| 전부 빈칸                    | 네이버가 화면 구조를 바꿈. 코드의 선택자를 다시 찾아야 함     |
| 일부만 빈칸                   | 네이버에 우편번호가 안 뜨는 주소 (오래된 지번주소, 신축, 오타) |
| 느리거나 멈춤                  | 건수가 많음. 나눠서 처리하고 6번으로 마무리             |

**옮겨 심기 전에** — 행정안전부 도로명주소 API(`business.juso.go.kr`)가 우편번호를 무료로 제공함. 승인키 발급이 필요한 대신 **깨지지 않고 약관 문제도 없음.** 이 도구를 그대로 쓰기 전에 먼저 검토할 것. *본 도구는 승인키가 필요 없는 상황에서 빠르게 사용하기 좋음*

## 주의사항

AI를 쓰지 않아 대부분 해당 없음. 해당하는 4개만.

| ID | 위험 | 완화 | 남은 위험 |
|---|---|---|---|
| **P1** 책임성 | 사람 검토 지점이 없음. 틀린 우편번호로 우편물이 반송되면 책임은 단체에 | 처음 10건 손 대조 | 주소록에 새 줄을 추가할 때마다 다시 확인해야 함 |
| **P4·G3** 개인정보 | **회원 주소가 검색어로 네이버에 전송됨.** 네이버는 검색 질의를 로그로 남김 | 이름 없이 주소만 전송 | 주소 전송 자체는 남음. **피해자 쉼터·활동가 자택처럼 주소만으로 민감한 항목은 넣지 말 것** |
| **G1** 정확성 | **조용한 실패.** 깨지면 오류가 아니라 빈칸이 나와 "우편번호 없음"으로 오인됨 | 처음 10건 대조 | 빈칸이 정상인지 고장인지 구분할 방법이 없음 |
| **G4** 약관 | 네이버 검색 결과 자동 수집. 이용약관상 제한 소지 | 소량·저빈도 사용 | 단체 이름으로 하는 일이므로 판단 필요. 공식 API로 바꾸면 사라지는 항목 |

해당 없음 — **P2**(단순 반복이라 훈련 가치 없음) · **P3**(사람을 분류하지 않음) · **P5·G5**(AI 생성물 아님) · **P6·G6**(생성형 AI 미사용) · **G2**(생성 결과물 없음)
